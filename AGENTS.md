# AGENTS.md

Проект: программа расчета и подбора армирования железобетонных элементов по СП 63 с применением ИНС.

## Главные правила для Codex

1. Не изобретать формулы.
2. Любая расчетная функция реализуется только на основании файла из `docs/formulas/`.
3. Нейросеть не является окончательным расчетчиком.
4. Каждый результат ML должен проверяться через `sp63_core`.
5. Все расчеты выполнять в системе: Н, мм, МПа.
6. В каждом расчетном модуле указывать:
   - пункт СП;
   - входные параметры;
   - единицы измерения;
   - выходные параметры;
   - ограничения применимости.
7. После изменения расчетного модуля обязательно запускать `pytest`.
8. После изменения публичной функции обновлять документацию.
9. Не добавлять новые зависимости без обоснования.
10. Не помещать в репозиторий полный текст СП или большие фрагменты нормативного документа; использовать краткие ссылки на пункты и собственное описание алгоритма.

## Definition of Done для расчетного модуля

Модуль считается готовым, если:
- есть реализация;
- есть минимум 3 unit-теста;
- есть контрольный пример;
- есть обработка некорректных входных данных;
- есть запись промежуточных значений в протокол;
- есть ссылка на пункт СП;
- все тесты проходят.

## Review checklist

При проверке кода обращать внимание на:
- ошибки единиц измерения;
- перепутанные знаки моментов, сил и напряжений;
- отсутствие проверки границ применимости;
- отсутствие проверки `x <= xi_R * h0` для изгиба;
- принятие unsafe-решения от нейросети без проверки через `sp63_core`;
- отсутствие теста на предельный случай.
