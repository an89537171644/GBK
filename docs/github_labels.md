# GitHub labels for Codex workflow

Recommended labels:

- codex-ready - task is ready for Codex
- codex-in-progress - Codex is currently working
- engineer-review - engineering review required
- formula-change - formula changes are involved
- ml-sandbox - ML sandbox work
- serviceability - second limit-state work
- validation - validation workflow
- dataset - dataset generation
- ui - user interface
- documentation - documentation-only task
- blocked - task is blocked

Labels can be created manually in GitHub repository settings.
