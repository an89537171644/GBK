# Контрольный лист пользовательской приёмки

Проверяемая версия, SHA-256 и дата испытания должны быть записаны до запуска.

## Установка и запуск

- [ ] Архив распакован в локальную папку без изменения структуры.
- [ ] SHA-256 манифеста и включённых файлов совпадают.
- [ ] `INSTALL_FROM_WHEEL.cmd` завершился без ошибки.
- [ ] `RUN_INTERACTIVE.cmd` запускает форму прямоугольной балки.
- [ ] `RUN_JSON_USER.cmd` обрабатывает включённый пример и сохраняет окно.
- [ ] `RUN_JSON.cmd` остаётся неблокирующим маршрутом автоматизации/CI.
- [ ] `OPEN_RESULTS.cmd` открывает локальный каталог результатов.
- [ ] Первым открыт верхнеуровневый `standalone_index.html`, а не raw
      `workflow/index.html`; `OPEN_RESULTS.cmd` используется лишь для папки.

## Исходные данные

- [ ] Размеры явно обозначены в миллиметрах.
- [ ] `cover_mm` интерпретируется как программное расстояние от грани бетона до
      наружной поверхности хомута; нормативный смысл не считается утверждённым.
- [ ] Изгибающий момент обозначен в кН·м.
- [ ] `moment_kNm` вводится как неотрицательный модуль, знак которого не выбирает
      растянутую грань.
- [ ] `tension_face` явно задан как `local_y_min` либо `local_y_max`.
- [ ] Физическое сопоставление локальных осей и граней не считается утверждённым
      и перед использованием передано на инженерную проверку.
- [ ] Поперечная сила обозначена в кН.
- [ ] Направление растянутой грани выбирается явно.
- [ ] Неподдерживаемые классы материалов отклоняются.
- [ ] `b_mm`, `h_mm`, `cover_mm`, `stirrup_diameter_mm` конечны и строго больше
      нуля; `cover_mm < h_mm`; диаметр хомута равен 6, 8, 10 или 12 мм.
- [ ] `moment_kNm` и `shear_kN` конечны и неотрицательны; ноль допустим.
- [ ] Режим не предлагает плиту, колонну или произвольное сечение.

## Каталог результата

- [ ] Для каждого отдельного расчёта выбран отдельный каталог результата.
- [ ] В управляемый программой каталог результата не помещены произвольные
      пользовательские файлы.
- [ ] В `case_id` нет ФИО, email, подписей или локальных путей.

## Результаты и защитные ограничения

- [ ] В результате присутствует `project_use = false`.
- [ ] В результате присутствует `requires_engineer_review = true`.
- [ ] Область статуса обозначена как `public`.
- [ ] Неприменимый случай возвращает `outside_applicability` или `fail`.
- [ ] Публичный результат не выдаёт утверждённую изгибную несущую способность.
- [ ] ML-результаты отсутствуют.
- [ ] Для запуска не запрашиваются ЛИРА-САПР или SCAD.
- [ ] Ошибка входного файла приводит к ненулевому коду завершения.
- [ ] Инженеру передаётся только верхнеуровневый `standalone_review_bundle.zip`,
      а не весь каталог результата или внутренний `workflow/deterministic_report.zip`.
- [ ] `standalone_review_metadata.json.code_identity.code_identity_status` равен
      `recorded_from_launcher_requires_manifest_match`.
- [ ] SHA-256 из `.code_identity.build_id=wheel-sha256:<sha256>` совпадает с
      `wheel_sha256` в `standalone_manifest.json`.
- [ ] Для `source-unverified` статус равен `unavailable_open_question`, и результат
      не передаётся как пакетное испытание.
- [ ] `pass` отдельной проверки не трактуется как общий результат, инженерный
      допуск или разрешение проектного применения.

## Решение пользователя

Выберите только один статус:

```text
ACCEPT_FOR_RESEARCH_TRIAL
ACCEPT_WITH_COMMENTS
REJECT
```

Положительное решение разрешает лишь внутреннюю исследовательскую проверку,
не разрешая проектное, производственное, нормативное или коммерческое применение.
