# План верификации v0.1

## Уровни проверки

1. Проверка единиц измерения.
2. Unit-тесты справочников материалов.
3. Unit-тесты отдельных расчетных функций.
4. Golden cases: контрольные ручные расчеты.
5. Сравнение с SCAD/LIRA для выбранных расчетных схем.
6. Проверка ML: все предложения ИНС должны проходить через `sp63_core`.
7. Анализ чувствительности входных параметров.
8. Утверждение границ применимости.

## Минимальный набор контрольных примеров

| № | Пример | Ответственный |
|---|---|---|
| 1 | Балка прямоугольная, изгиб, одиночная арматура | расчетный исполнитель |
| 2 | Балка прямоугольная, изгиб со сжатой арматурой | расчетный исполнитель |
| 3 | Балка с поперечной силой и хомутами | расчетный исполнитель |
| 4 | Плита как прямоугольный изгибаемый элемент | расчетный исполнитель |
| 5 | Сравнение результата с SCAD/LIRA | команда |

## Правило приемки ML

Нейросетевая модель может ошибиться в прогнозе, но программа не имеет права принять небезопасное решение. Приемка результата выполняется только после проверки через расчетное ядро.
