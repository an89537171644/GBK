# Руководство пользователя

## 1. Назначение программы

GBK / `sp63-rc-ai` — MVP-прототип для предварительного расчета и подбора
армирования прямоугольных железобетонных элементов по реализованным карточкам
проекта. Программа помогает получить проверяемый расчетный протокол, варианты
продольной и поперечной арматуры, а также демонстрационные данные для анализа.

## 2. Область MVP

Текущая область:

- прямоугольные изгибаемые элементы без предварительного напряжения;
- тяжелый бетон B15-B40 из draft-таблицы проекта;
- арматура A240/A400/A500 из draft-таблицы проекта;
- проверка изгиба и поперечной силы по утвержденным MVP formula cards;
- deterministic подбор продольной арматуры и хомутов;
- расчетный протокол JSON/HTML;
- демонстрационный CLI и Streamlit-интерфейс.

## 3. Ограничения

MVP не заменяет полный проектный расчет. Не реализованы: кручение,
продавливание, колонны, тавровые и сложные сечения, трещиностойкость, прогибы,
нелинейная деформационная модель, особые воздействия и полный набор проверок СП.

## 4. Единицы измерения

Внутренние единицы:

- силы: Н;
- моменты: Н*мм;
- размеры: мм;
- напряжения: МПа = Н/мм2;
- площади арматуры: мм2.

CLI и Streamlit могут принимать момент в кН*м и поперечную силу в кН, после чего
переводят их в рабочие единицы проекта.

## 5. Ввод исходных данных

Основные входные параметры:

- `b`, `h`, `cover`, `stirrup_diameter`, `main_bar_diameter`;
- классы бетона, продольной и поперечной арматуры;
- изгибающий момент `M`;
- поперечная сила `Q`.

Для инженерного применения все исходные данные должны быть проверены
специалистом до и после расчета.

## 6. Расчет через CLI

Примеры:

```bash
sp63-core design --cover 32 --moment 150000000 --q 80000
sp63-core design --cover 32 --moment 150000000 --q 80000 --report-html reports/demo.html
sp63-core bending --cover 32 --as-area 942.48 --moment 150000000
sp63-core shear --cover 32 --q 80000 --asw 100.53 --sw 200
```

Команда `design` использует deterministic service `design_rectangular_element()`.

## 7. Расчет через Streamlit

Установка UI-зависимости и запуск:

```bash
python -m pip install -e ".[dev,ui]"
streamlit run apps/streamlit_app.py
```

Streamlit-прототип предназначен для демонстрации и предварительного анализа.

## 8. Интерпретация статусов

- `pass` — проверка прошла в рамках реализованной MVP-логики.
- `fail` — несущей способности или подходящего варианта недостаточно.
- `review_or_fail` — результат требует инженерного рассмотрения, например при
  превышении предельной относительной высоты сжатой зоны.

## 9. Расчетный протокол

Протокол содержит исходные данные, материалы, геометрию, армирование, результаты
проверок, предупреждения, итоговый статус и `requires_engineer_review`.
Поддерживается экспорт в JSON и HTML.

## 10. Предупреждение об инженерной проверке

Все draft-материалы, расчетные таблицы, golden cases, отчеты, ML-прогнозы и UI
результаты требуют инженерной проверки. Результаты MVP не являются
самостоятельной проектной документацией.
