# Очередь задач для Codex

## Задача A1. Каркас проекта

Промпт:

```text
Создай Python-проект со структурой src/sp63_core, tests, docs, data. Настрой pyproject.toml, pytest и ruff. Добавь минимальный тест, чтобы pytest проходил.
```

Критерий приемки: `pytest` проходит, проект импортируется.

## Задача A2. Единицы измерения

```text
Реализуй src/sp63_core/units.py. Все расчеты в проекте должны использовать Н, мм, МПа. Добавь функции kN_to_N, kNm_to_Nmm, cm2_to_mm2 и тесты.
```

## Задача B1. Справочник бетона

```text
Реализуй справочник бетона для B15, B20, B25, B30, B35, B40. Данные вынеси в таблицу. Добавь Pydantic-модель и тесты.
```

## Задача B2. Справочник арматуры

```text
Реализуй справочник арматуры A240, A400, A500. Добавь каталог диаметров и функцию area_by_diameter(d). Добавь тесты.
```
