# Заметки для регистрации программы для ЭВМ

Этот документ является подготовительной заметкой. Он не содержит персональные
данные, закрытые материалы, полный текст СП или полную грантовую заявку.

## 1. Название программы

GBK / `sp63-rc-ai`: программный прототип предварительного расчета и подбора
армирования железобетонных элементов.

## 2. Назначение

Программа предназначена для демонстрационного и предварительного анализа
прямоугольных железобетонных элементов, формирования расчетного протокола,
генерации проверенных расчетных примеров и исследования ML-помощников.

## 3. Функциональные возможности

- справочники материалов draft-уровня;
- геометрия прямоугольного сечения;
- расчет изгиба и поперечной силы в рамках MVP;
- подбор продольной и поперечной арматуры;
- расчетный протокол JSON/HTML;
- генерация датасета;
- baseline и neural ML-прогноз `As_required`;
- CLI и Streamlit-прототип.

## 4. Язык программирования

Основной язык: Python 3.10+.

## 5. Используемые библиотеки

Основные:

- numpy;
- pandas;
- pydantic;
- pytest;
- ruff.

Optional:

- scikit-learn;
- joblib;
- streamlit.
