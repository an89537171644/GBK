# Acceptance Checklist

Before engineering use, confirm:

- deterministic reports have been reviewed;
- golden validation passes;
- manual verification cases pass;
- material catalog values have engineer verification evidence;
- external validation evidence is filled by an engineer;
- protected files guard passes or changes are explicitly reviewed;
- ML remains advisory-only;
- `ml_ready_for_project_use = false`;
- no generated smoke artifacts are committed;
- no full SP 63 text, personal data, grant documents, or closed SCAD/LIRA files
  are committed.
