# Project Template

Create a starter handoff folder:

```bash
python -m sp63_core project-template \
  --output-dir reports/project_template \
  --json
```

The generated folder contains editable input JSON, external validation and
material verification CSV templates, recommended run commands, an acceptance
checklist, and a SHA256 manifest.

This package does not certify a design, does not update material values, and
does not make ML project-ready. Fill evidence templates manually and review all
deterministic outputs with an engineer.
