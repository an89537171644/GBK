# SP63 Core User Manual

This manual describes the current draft-MVP engineering workflow for
rectangular reinforced concrete beam checks, report generation, validation
evidence, and advisory ML safeguards.

The software is not certified. Deterministic SP63 checks, external validation,
material verification, and engineer review remain mandatory.
