# Техническое задание v0.1

## Назначение

Создать программный прототип для расчета и подбора армирования железобетонных элементов по СП 63 с применением нейросетевой surrogate-модели.

## Область MVP

- Элемент: балка или плита, работающая на изгиб.
- Сечение: прямоугольное.
- Арматура: без предварительного напряжения.
- Материалы: тяжелый бетон, арматура A400/A500 для продольной арматуры, A240/A400/A500 для поперечной.
- Расчеты: прочность нормального сечения, поперечная сила, подбор арматуры, расчетный протокол.

## Что не входит в MVP

- предварительно напряженные элементы;
- кручение;
- продавливание;
- колонны;
- нелинейная деформационная модель;
- автоматическая работа с BIM/IFC;
- окончательный расчет здания как конструктивной системы.

## Принцип применения ИНС

ИНС используется для прогнозирования потребности в армировании и ранжирования вариантов. Окончательное решение принимается только после проверки через `sp63_core`.

## Единицы измерения

- силы: Н;
- моменты: Н*мм;
- размеры: мм;
- напряжения: МПа = Н/мм²;
- площади арматуры: мм².
