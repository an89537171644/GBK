# Ограничения применимости

MVP применим только для предварительного анализа прямоугольных изгибаемых
железобетонных элементов без предварительного напряжения.

## Что поддержано

- прямоугольное сечение;
- тяжелый бетон B15-B40 из draft-таблицы проекта;
- арматура A240/A400/A500 из draft-таблицы проекта;
- изгиб прямоугольного сечения по MVP formula card;
- поперечная сила по MVP formula card;
- подбор продольной арматуры и хомутов через deterministic checks;
- расчетный протокол и draft UI.

## Что не поддержано

Не учитываются:

- кручение;
- продавливание;
- колонны;
- тавровые, двутавровые и произвольные сечения;
- предварительное напряжение;
- трещиностойкость;
- прогибы;
- нелинейная деформационная модель;
- огнестойкость и особые воздействия;
- анкеровка, нахлесты и детальная конструкторская проработка;
- полный проектный расчет здания или сооружения.

## Важное предупреждение

MVP не является заменой полного проектного расчета. Все результаты требуют
проверки квалифицированным инженером и не должны использоваться как
самостоятельная проектная документация.
