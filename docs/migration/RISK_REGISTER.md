# RISK REGISTER

## 1. Шкала

Вероятность и влияние: `LOW`, `MEDIUM`, `HIGH`. Статус решения использует
только `CONFIRMED`, `ASSUMPTION`, `OPEN_QUESTION`, `REJECTED`.

## 3. Приоритеты обработки

1. `R-001`–`R-008`: до утверждения формул и контрольных примеров.
2. `R-009`–`R-011`: до расширения входного и end-to-end scope.
3. `R-012`: до любого ML-релиза.
4. `R-013`: до готовности PR к merge; автоматическое слияние запрещено.
5. `R-014`–`R-015`: постоянные процессные ограничения.

Порядок является `ASSUMPTION`, основанной на тяжести последствий; инженерная
и проектная проверка приоритета обязательна.

## 4. Критерий остановки

Наличие открытого риска с влиянием `HIGH` запрещает `project_use=true` и
утверждение нормативных формул. Текущий статус пакета: возврат на инженерную
проверку.
